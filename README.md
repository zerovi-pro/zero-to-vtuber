# ZERO TO VTUBER - GitHub Pages

## 画像を入れる場所

`images` フォルダに画像を入れてください。

### 必要な画像

- `logo.png` → ヘッダー左上のロゴ
- `character.png` → トップページのVTuber立ち絵
- `project.jpg` → PROJECT部分の大きな画像
- `story.jpg` → STORY部分の画像
- `recruit.jpg` → RECRUIT部分の画像
- `vision.jpg` → VISION部分の画像

ファイル名を同じにすれば、自動的にサイトへ表示されます。

### Googleフォーム

`index.html` の `https://forms.google.com/` を、自分のGoogleフォームURLへ変更してください。

## GitHub Pages

GitHubに `index.html`、`style.css`、`script.js`、`images` フォルダをアップロード。
Settings → Pages → Deploy from a branch → main / root で公開できます。
